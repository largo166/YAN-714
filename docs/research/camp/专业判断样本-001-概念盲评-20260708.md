# 专业判断样本-001 · 概念产出盲评（2026-07-08）

> **这是什么:** ROM-AI 第一份「专业否定」语料——一位建筑事务所负责人对 AI 概念产出的三组盲评判断,含五维勾选、整体判定与判断理由。
> **为什么值钱:** 所有人都能调大模型,没人有"什么是专业的建筑判断"的标注数据。本样本库是垂类认知护城河的种子。
> **入库时机(已裁决 2026-07-08):** 本文件现在只做纯文档存档;"入库认知脊椎/type=专业判断样本/供 prompt 引用"的入库工程**排在主线 P0 之后**,现在不开支线。
> **实验协议:** 3 个真库真实项目材料 × 两版产出(A=裸问单发 / B=锻造链 compete→concept→judge→writer),甲乙盲化随机,评审人不知来源。全文见《C-P0盲评报告》(工序全记录)与《C-P0盲评包》(盲评态原文+勾选)。

## 二、评审人判断理由(负责人原话口径,判断的核心语料)

1. **"三样本我都倾向'给多个可落地方向'的版本,否掉了'下单一判断/说不成立'的版本。"** ——投标前期要的是可反应的选项集,不是替人做完的决定。
2. **"否定可以,但是现在否定的都过于不专业了,且明显没有落地性。"** ——不反对否定本身,反对没挣到资格的否定:论据浅(条款读半截就下结论)、判断出圈(跑向定价/政策套利,设计院画不出来)。
3. **"judge 的'不专业'本质是模型的建筑判断能力不够,不是机制能补的——在这上面堆工程是白费。"** ——能力问题不能用流程问题的解法。

### 2.1 逐样本否定理由(评审人补记原话,2026-07-08 照录,不改写)

**样本1 · 石家庄市庄:**
> 链版的问题是:它把项目判断推向了"金融定价/营销策略",但没有回到建筑设计动作本身。所谓"噪音-视野双梯度定价模型"听起来锋利,但不能直接指导总图、抬板、连桥、归家流线、展示区和庭院组织。裸问虽然概念词偏常见,但"悬浮绿洲 / 内向街坊 / 线性地标"至少还能转译成空间结构,所以赢。

**样本2 · 济南长岭山 E15:**
> 链版的问题是:它只抓住了"界面先发"和"时间差",判断窄了,丢掉了这个项目真正的设计燃料——13 米高差、山体关系、24m/36m 限高、会所、入口大堂和台地剖面。裸问的"山居峡谷"虽然有概念壳,但它能继续推导剖面、会所、庭院、山景轴和归家体验,更接近建筑方案工作。

**样本3 · 那河沟:**
> 链版如实否定候选方向是诚实的,但不够专业服务。资料不足时,正确输出不应该只是"三个概念均不成立",而应该切换为"规范策略地图 / 资料缺口清单 / 设计自由度判断"。裸问虽然也有概念化问题,但至少提供了若干可讨论方向;链版停在否定层面,没有给下一步工作路径,所以整体输。

## 三、从五维勾选里读出的「专业判断结构」(可复用的评分尺雏形)

1. **锋利度 3/3 全归链,但整体 0:3——评审人的偏好结构是字典序的**:可画性/贴合度/有骨是先决维度,锋利度只是同等专业水平下的加分项。**敢说话不值钱,说得对且能画才值钱;但"敢"被三次承认,说明评审人不反对判断本身,反对的是没挣到资格的判断。**
2. **"可执行性"在建筑语境=可画性**——裸问每方向带空间原型(台地/合院/城墙-瓮城)与形式灵感,团队次日能上手;链的幸存者(定价模型/界面导则)属营销与管控策略,无法转化为图纸。**评分尺第一问:这个概念能不能画出来?**
3. **"独占性"评审人给了裸问,尽管链专门优化这一维**——链的"独占句"三次自检全部失败(换个项目仍成立),而裸问的方向因带具体场地条件(13米高差/中华大街界面)反而更"长在这块地上"。**推论:独占性来自场地基因的具体性,不来自措辞的排他性。**
4. **样本3 的教训:否定的资格线**——链对襄阳规范集的三条否定,其一(错位日照)甚至引用了与规范表格相反的"规律"。**专业否定的最低门槛:引用的每一条规范条款必须完整、准确、可查证。** 半截条款("不超过上…")不许作为立论或否决依据。

## 四、后续路线(已裁决)

- **不建 forge 系统**(两表/回路/命名迁移全搁置);锻造链设计文档转能力储备。
- **归因口径(防重复发明,评审人确认):被证伪的是"目标函数(消除平庸只留一个)与裁判权设计(judge 握生杀之门)",不是"链式/分阶段工序"本身**——同样的四段结构换目标函数(每方向给排布逻辑/日照初判/成本敏感点)胜负未必如此。半年后若有人重提"分阶段管线",先读本条。
- **废墟三抢救(评审人确认):** ①红海/撞车情报——降为**标注**不做否决;②张力挖掘——做方向的**输入燃料**不做杀人刀;③**盲评协议**——保留为 ROM-AI 能力评测工具。
- **攒能力三路:** ①专业语料沉淀——规范条文库(完整条款,不是半截)、本样本这类"专业否定/正反案例"持续积累(入库工程排 P0 后);②更强的专业 prompt(把§三的评分尺写进生成侧:每方向必带空间原型+可画性自检);③等底层模型迭代。
- **复活条件(条件性复测,评审人确认):** 专业语料 v1 建成后,用同一盲评协议(3真实样本/盲化/五维)花几毛钱复测;**链胜出才有资格重提锻造链**。不设复测点="死刑";设了="缓刑+明确假释条件"。

## 五、给生成侧 prompt 的直接输出(本样本的第一笔利息)

未来任何"概念生成"类功能,系统 prompt 应吸收:
- 产出**3-5 个方向**,不做单一裁决;每方向必含:设计叙事 / **空间原型** / 形式灵感 / 与本场地具体条件的锚点(至少一个具体数值或地名)。
- 附**撞车风险标注**(红海情报作为标注保留,不作为否决):"此方向常见于同类投标,若用需在X上做出差异"。
- **不许**:引用不完整规范条款立论;给出设计学科外的"概念"(纯定价/纯政策套利);以"材料不足"拒绝服务——材料薄时照样给方向,并明示"以下基于有限材料,建议补充X后深化"。
