## 主题1：建筑方案前期（强排阶段）需要哪些资料？

### 1.1 资料维度全景

根据搜索和行业实践，强排阶段所需资料可分为以下维度：

| 维度 | 核心内容 | 甲方提供/设计方自搜集 |
|------|----------|---------------------|
| **规划条件** | 用地红线图、规划条件书、控规图则、容积率、限高、密度、绿地率、退界要求、配套要求 | 甲方（投资部从规划局获取） |
| **市场调研** | 区域竞品分析、产品定位、户型配比建议、售价预期、客群画像 | 甲方（营销部提供） |
| **甲方任务书** | 设计任务书、产品定位报告、业态组合要求、交付标准、特殊要求 | 甲方（设计部/营销部编制） |
| **设计规范** | 当地城市技术管理规定、日照规范、消防规范、停车位配建标准、建筑间距要求 | 设计方为主（需查地方规范） |
| **竞品分析** | 周边在售项目总图、户型、售价、去化情况、产品特征 | 设计方自搜集+甲方提供 |
| **成本约束** | 各业态成本指标、目标利润率、地价上限、建安成本标准 | 甲方（成本部提供） |
| **场地条件** | 地形图、地质勘察报告、周边现状（建筑/道路/管线）、航拍/卫星图 | 甲方提供+设计方踏勘 |

> 来源：综合 [搜索] 腾讯新闻《强排是什么？怎么做？一篇文章搞懂！》(2020)、[搜索] 桂林金瓴建筑设计事务所《建筑设计中的强排是什么意思》(2021)、[搜索] 融创设计研发流程文件(2017)、[经验推断]

### 1.2 规划条件——最关键的基础资料

**搜索发现的规划条件清单：**

规划条件通常由规划局在土地出让时提供，核心要素包括：

- **规划用地性质**：住宅、商业、办公、混合等 [搜索] 桂林金瓴建筑设计事务所
- **用地面积**：红线范围内的净用地面积
- **容积率**：通常有上限，部分地块有下限（如≥1.0） [搜索] 浙江省控制性详细规划文件
- **建筑限高**：直接影响可排布的层数，进而影响栋数计算
  - 公式：`最大层数 = 限高 / 层高（通常按3m计算）` [搜索] 桂林金瓴建筑设计事务所
- **建筑密度**：与首层建筑面积直接相关，影响可排布的基底面积
- **绿地率**：通常≥30% [搜索] 衢州市2012年政府文件
- **建筑退界要求**：后退道路红线、用地红线的距离 [搜索] 建筑设计防火规范
- **配建要求**：幼儿园、社区用房、养老用房、垃圾站、开闭所等 [搜索] 融创设计研发流程
- **车位配比**：住宅通常≥1.2辆/户 [搜索] 衢州市政府文件
- **其他特殊要求**：如建筑风格、立面材质、装配式建筑比例、海绵城市要求等

> 来源：[搜索] 多源综合

### 1.3 市场调研——甲方必须提供的关键输入

**搜索发现的市场调研输入内容：**

营销部/市场部的输入通常包括：

1. **产品定位**：刚需、改善、豪宅、混合定位 [搜索] 腾讯新闻(2020)
2. **户型配比要求**：各面积段的户数比和面积比
   - 例如：高层120㎡占40%、140㎡占35%、洋房160㎡占25% [搜索] 融创设计研发流程文件
3. **售价预期**：各业态的预计销售单价
4. **竞品信息**：周边在售项目的户型、总图、售价、去化速度
5. **客群画像**：目标客户的年龄、家庭结构、购买力、偏好
6. **特殊要求**：如是否需要示范区、售楼处位置、样板房要求等

> 来源：[搜索] 腾讯新闻(2020)、[搜索] 融创设计研发流程(2017)、[搜索] 房地产营销部工作职责文档

### 1.4 设计规范——设计方必须自行搜集和解读

**搜索发现的设计规范清单：**

- **城市技术管理规定**：各地规划局的内部技术规定，如退界、间距、停车、配套等 [搜索] 桂林金瓴建筑设计事务所
- **日照规范**：日照间距系数、日照分析软件要求、大寒日/冬至日标准 [搜索] 甘肃省城镇规划管理技术规程
- **消防规范**：
  - 防火间距 [搜索] 巩义市控制性详细规划
  - 消防车道宽度（通常≥4m） [搜索] 拿地强排设计要点分析PPT
  - 消防登高面要求 [搜索] 拿地强排设计要点分析PPT
- **建筑设计防火规范** GB50016-2014（2018年版） [搜索] 多源
- **民用建筑设计通则** GB50352-2019 [搜索] 巩义市控规
- **住宅设计规范** GB50368-2005 [搜索] 毕设任务书
- **汽车库建筑设计规范** JGJ100-98 [搜索] 毕设任务书
- **地方特殊规定**：如各地的装配式建筑要求、绿色建筑要求、海绵城市要求等

> 来源：综合 [搜索] 多源规范文件

### 1.5 资料缺失导致返工的高风险项

**搜索和行业标准中发现的"资料缺失→返工"案例：**

| 缺失资料 | 可能导致的问题 | 来源 |
|----------|--------------|------|
| 规划条件中的"配套要求"不清晰 | 遗漏幼儿园/社区用房/养老用房等，导致报规不通过，总图返工 | [搜索] 融创设计研发流程 |
| 日照规范（尤其界外日照） | 排布完成后发现对周边建筑日照影响超限，需要调整总图 | [搜索] 桂林金瓴建筑设计事务所 |
| 地质勘察报告 | 地下水位不明，地库设计返工；或土质情况导致基础形式变更 | [搜索] 城市轨道交通车辆基地工程接口管理探讨 |
| 周边现状建筑高度/轮廓 | 日照分析需要界外建筑轮廓，缺失时需要镜像法推算，增加误差 | [搜索] 桂林金瓴建筑设计事务所 |
| 城市技术管理规定中的停车位配建标准 | 车位数不足或过多，影响经济测算和地库面积 | [搜索] 衢州市政府文件 |
| 竖向标高/地形资料 | 土方平衡计算偏差，导致场地设计返工 | [搜索] 城市轨道交通车辆基地工程接口管理探讨 |
| 规划道路开口位置 | 出入口设置不符合规划要求，需要调整总图 | [搜索] 五河县城南地块招标文件 |
| 环评/交评等专项要求 | 总图布局不符合规划要求，方案无法通过 | [搜索] 城市轨道交通车辆基地工程接口管理探讨 |
| 甲方任务书中的"交付标准" | 户型设计标准不清，导致后期修改 | [搜索] 融创设计研发流程 |
| 产品定位/户型配比 | 排布完成后发现与市场定位不符，需要调整产品组合 | [搜索] 无效成本专项审计方案 |

> 来源：综合 [搜索] 多源 + [行业标准] 建设工程设计优化服务标准(2023)

## 主题2：强排阶段的标准工作流程

### 2.1 从拿地到报集团的整体流程

**搜索发现的标准流程（以融创设计研发流程为参考）：**

```
投资部拿地 → 提供红线图+规划条件 → 营销部提供产品定位+户配
        ↓
    设计部接收资料
        ↓
    设计部整图强排（7天左右）
        ↓
    输出：强排方案（CAD总图+户型分配彩图+体块模型）
        ↓
    投资部+成本部+营销部联合测算
        ↓
    输出：项目利润率、投资可行性报告
        ↓
    报集团/投决会评审
        ↓
    拿地决策/调整方案
```

> 来源：[搜索] 融创设计研发流程(2017)、[搜索] 腾讯新闻(2020)

### 2.2 强排阶段的详细步骤

**搜索发现的"规划设计强排阶段典型流程"（筑楼人资源）：**

| 步骤 | 目标 | 输入 | 输出 | 关键控制点 |
|------|------|------|------|----------|
| Step1: 用地分析 | 确定用地红线、建筑退界 | 上位规划+城市规划管理条例+土地出让条件 | 退界后的可用用地范围 | 退界距离必须准确 |
| Step2: 单体选型 | 确定产品的具体选型 | 层数+开间+单层建筑面积 | 标准户型单元平面 | 户型需满足户配要求 |
| Step3: 间距确定 | 确定建筑间距 | 日照间距+消防间距+地库关系 | 各方向最小间距 | 需考虑界外日照影响 |
| Step4: 极限容积率测算 | 确定各产品标准组团的极限容积率 | 土地退界+单体选型+间距确定 | 极限容积率数据 | 支持后续产品配比 |
| Step5: 产品分布分析 | 确定产品组合和分布 | 极限容积率+市场定位+货值最大化 | 产品分布策略 | 需平衡货量与货值 |
| Step6: 强排成果输出 | 输出合理的强排方案 | 以上所有分析结果 | CAD总图+指标表+模型 | 需满足所有规划条件 |

> 来源：[搜索] 筑楼人《规划设计强排阶段典型流程解析》、[搜索] 拿地强排设计要点分析PPT

### 2.3 设计院内部和甲方的协作流程

**搜索发现的协作分工：**

**甲方（开发商）内部：**
- **投资部/发展部**：从政府获取红线图、规划条件、控规图，传递给设计部
- **营销部**：提供市场调研、产品定位、户型配比、售价预期 [搜索] 腾讯新闻(2020)
- **设计部**：接收所有资料，编制设计任务书，组织设计院进行强排 [搜索] 新疆新发房地产开发有限公司设计专员招聘
- **成本部**：提供各业态建安成本，参与经济测算
- **财务部**：进行投资回报测算

**设计院内部：**
- **总图设计师/规划师**：负责总图排布、日照分析、指标计算 [搜索] 建筑英才网总图设计师招聘
- **建筑设计师**：负责户型选型、单体设计、平立剖绘制
- **结构工程师**：配合确定结构形式、层高、地下室结构
- **设备工程师**：配合确定地库通风、机电管井位置
- **经济测算人员**：配合计算指标、面积、车位数等

**协作流程中的常见问题：**
- 设计院往往需要"催"甲方提供规划条件，因为甲方投资部从规划局获取资料需要时间 [搜索] 腾讯新闻(2020)
- 营销部的户型配比可能"朝令夕改"，导致设计院反复调整 [搜索] 无效成本专项审计方案
- 甲方设计部需要"研判设计院出具方案的合理性" [搜索] 新疆新发房地产开发有限公司设计专员招聘

> 来源：综合 [搜索] 多源

## 主题3：住宅项目（尤其是高层住宅）强排的核心关注点

### 3.1 核心指标及其相互关系

**搜索发现的指标关系图：**

```
容积率（上限）
    │
    ├──→ 总建筑面积 = 用地面积 × 容积率
    │         │
    │         ├──→ 地上建筑面积（住宅+商业+配套）
    │         │         │
    │         │         ├──→ 住宅面积 = 总户数 × 户均面积
    │         │         │         │
    │         │         │         ├──→ 栋数 = 住宅面积 / (户均面积 × 每层户数 × 层数)
    │         │         │         │
    │         │         │         └──→ 层数由限高决定（层高按3m计）
    │         │         │
    │         │         └──→ 商业面积 + 配套面积（幼儿园、社区用房等）
    │         │
    │         └──→ 地下建筑面积（地库+设备用房+人防）
    │
    ├──→ 建筑密度（上限）→ 影响基底面积 → 影响可排布栋数
    │
    ├──→ 绿地率（下限）→ 影响景观/绿化面积
    │
    ├──→ 限高 → 影响层数 → 影响栋数
    │
    └──→ 建筑间距（日照+消防）→ 影响总图排布效率
```

> 来源：[搜索] 桂林金瓴建筑设计事务所(2021)、[搜索] 拿地强排设计要点分析PPT

### 3.2 各指标详解

#### 3.2.1 容积率

- **定义**：总建筑面积 / 用地面积（通常不包括地下面积） [搜索] 容积率及总图规划课题研究分享
- **关键原则**："损失可销售部分的容积率等于白白扔掉一块利润" [搜索] 容积率及总图规划课题研究分享(2017)
- **影响容积率的客观因素**：日照规范、间距要求、退红要求、限高要求
- **影响容积率的人为因素**：产品定位、不利地块利用度、单体楼型选择 [搜索] 容积率及总图规划课题研究分享
- **不平衡使用容积率**：是提高货值的有效办法，做总图前要进行业态组合比例模型推演 [搜索] 容积率及总图规划课题研究分享

#### 3.2.2 限高与层数

- **最大层数 = 限高 / 层高（一般按3m计算）** [搜索] 桂林金瓴建筑设计事务所
- 超高层（>100m）会增加结构成本、消防成本、电梯成本，通常需要特殊论证 [搜索] 搜狐《周二风暴营销说》(2017)
- 北方地区日照要求高，高层最好做正南北向 [搜索] 桂林金瓴建筑设计事务所

#### 3.2.3 日照

- **日照间距计算**：L = i × (H - h)，其中 i 为日照间距系数，H 为遮挡建筑高度，h 为被遮挡建筑窗台高度 [搜索] 甘肃省城镇规划管理技术规程
- **方位折减**：不同方位角有不同的折减系数 [搜索] 甘肃省城镇规划管理技术规程
- **界外日照影响**：在某些情况下，需要考虑场地内建筑对界外建筑的影响；如果没有界外建筑轮廓，需要采用"镜像法"推算 [搜索] 桂林金瓴建筑设计事务所
- **中高层、高层住宅**的日照间距通常采用日照分析软件计算，而非简单系数法 [搜索] 甘肃省城镇规划管理技术规程

#### 3.2.4 消防间距与消防车道

- **防火间距**：符合《建筑设计防火规范》GB50016-2014 [搜索] 巩义市控规
- **消防车道**：通常≥4m宽度，高层住宅需标注消防登高面位置 [搜索] 拿地强排设计要点分析PPT
- **消防登高面**：需满足登高面与建筑之间的间距要求 [搜索] 拿地强排设计要点分析PPT
- **注意**：正南北向布局在北方有利于日照，但可能不利于消防环道的布置 [搜索] 桂林金瓴建筑设计事务所

#### 3.2.5 户型配比与面宽进深

- **户型配比**：由营销部根据市场调研提供，是强排的核心输入 [搜索] 腾讯新闻(2020)
- **面宽进深比**：黄金比例约为 1:1.5（如开间4m，进深6m） [搜索] 买房攻略(2025)
- **开间**：房屋主要采光面的宽度
- **进深**：与开间垂直的深度
- **大户型**通常需要放在地块最有利的位置（中心位置、景观资源好），小户型可放在周边或有不利因素的位置 [搜索] 桂林金瓴建筑设计事务所

#### 3.2.6 地库

- **地库面积计算**：地下停车位数 × 单车位面积（通常约42㎡/车位） [搜索] 总图技术指标计算表
- **地库出入口**：当地下停车>500辆时，需至少3个地下车库出入口 [搜索] 拿地强排设计要点分析PPT
- **人防要求**：通常按地上建筑面积的一定比例配建 [搜索] 巩义市控规
- **地库层高**：影响土方开挖量和建安成本
- **快速开发策略**：可让一期开发楼栋避开地库，保证快速施工 [搜索] 保利金华项目投标方案

#### 3.2.7 商业配比

- **商业一般沿用地边界布置**，会吃掉一部分住宅面积 [搜索] 桂林金瓴建筑设计事务所
- **商业价值判断**：临城市主干道商业价值高，临绿化带和河流商业价值低 [搜索] 桂林金瓴建筑设计事务所
- 商业面积不是越多越好，需要根据周边人流、消费力合理配置 [搜索] 筑龙学社

### 3.3 指标之间的冲突点

**搜索和经验推断中发现的常见冲突：**

| 冲突双方 | 冲突表现 | 常见处理方式 |
|----------|----------|-------------|
| 容积率 vs 日照 | 做满容积率可能导致日照间距不够 | 调整楼栋角度、减少部分楼栋层数、或采用"高低配" |
| 建筑密度 vs 绿化率 | 密度高则绿化率低 | 优化首层布置，利用屋顶绿化、架空层等 |
| 户型面宽 vs 总图排布效率 | 大面宽户型需要更多间距 | 在南侧或景观侧布置大面宽，其他方向布置小面宽 |
| 地库面积 vs 成本 | 地库越深成本越高 | 控制地库层数，尽量在1层内解决停车 |
| 消防 vs 日照 | 正南北向有利于日照，但可能不利于消防环道 | 适当调整角度，兼顾两者 |
| 商业 vs 住宅 | 商业占容积率，减少住宅面积 | 控制商业比例，将商业放在价值最高的沿街面 |
| 限高 vs 栋数 | 限高越低，需要的栋数越多 | 在满足日照的前提下，尽量增加单栋面宽或每层户数 |
| 快速开发 vs 货值最大化 | 快速开发需要避开地库，但可能影响整体规划 | 分期开发，一期先开发无地库区域 [搜索] 保利金华项目 |

## 主题5：总图→户型→立面的展开逻辑

### 5.1 先定总图还是先定户型？

**搜索发现的逻辑顺序：**

根据多个来源，强排的逻辑顺序是：

1. **先满足"量"的要求**（容积率、密度、限高） [搜索] 桂林金瓴建筑设计事务所
2. **再向户型配比接近** [搜索] 桂林金瓴建筑设计事务所
3. **逐步优化产品组合**（减少高层栋数、增加洋房量、提升溢价） [搜索] 桂林金瓴建筑设计事务所

**具体流程：**
- 先根据规划条件确定可用的建筑基底面积和总建筑面积
- 根据户型配比选择合适的户型单元
- 计算"栋数 = 住宅面积 / (户均面积 × 每层户数 × 最大层数)" [搜索] 桂林金瓴建筑设计事务所
- 在CAD中排布楼栋位置，满足间距、日照、消防等要求
- 根据排布结果调整户型组合

> 来源：[搜索] 桂林金瓴建筑设计事务所(2021)、[搜索] 拿地强排设计要点分析PPT

### 5.2 总图定了之后户型如何适配？

**搜索发现的原则：**

- 在标准组团的极限容积率测算中，核心要素有三：土地分析、单体选型、建筑间距；三者综合作用，支持后续产品配比 [搜索] 筑楼人《规划设计强排阶段典型流程解析》
- 户型配比修改后，总图楼栋布局及层数需要相应调整 [搜索] 苏州高新区规划方案公示(2023)
- 实际项目中，"因产品户型配比修改，总图楼栋布局及层数调整，经济技术指标相应调整"是常见现象 [搜索] 苏州高新区规划方案公示(2023)
- 这意味着：总图和户型之间是**迭代关系**，不是一次性确定

> 来源：[搜索] 筑楼人、苏州高新区规划方案公示(2023)

### 5.3 立面是强排阶段的内容吗？

**搜索发现：**

- **强排阶段**：立面通常不是重点。强排的核心是总图和指标，"强排与建筑设计无关，主要是在容积率、退线、建筑密度、限高、日照间距等规划指标下，去结合当地不同产品的营销情况，来排出各种追逐利润最大化的极端产品规划方案" [搜索] 搜狐《周二风暴营销说》(2017)
- **方案设计阶段**：立面开始成为重要内容。根据上坤松江项目标准，方案设计阶段需要包含"主要区域效果图"、"立面分色图" [搜索] 上坤松江项目招募公告
- **方案深化阶段**：立面控制手册、关键节点详图（阳台栏杆、空调机位、立面构架等）成为正式交付成果 [搜索] 上坤松江项目招募公告
- **NOAH软件的工作流**：从总图 → 平面 → 立面的全流程，说明立面是后续阶段才深入的内容 [搜索] 豆瓣/诺亚软件更新说明(2022)

> 来源：综合 [搜索] 多源
