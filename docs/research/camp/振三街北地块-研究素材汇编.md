- 屋面：挤塑聚苯板隔热
- 户内门：PVC木质户内门
- 大堂：地砖或石材，首层墙砖，标准层艺术涂料
- 楼梯间：负一层至三层地砖，其余水泥地面抹光

## 四、甲方集团文件的关键要求（从事业一部PDF提取）

### 4.1 上报材料要求

1. **必须包含**：营销"一房一价"专项 + 成本适配专项分析
2. **必须包含**：地库专项方案 + 首层拼合总平面方案
3. **户型平面页**：须附上该户型的总图位置示意
4. **未包含以上专项，不允许上会审议**

### 4.2 可售比控制

- 北部区域平均值：0.72
- 低于平均值的项目须做专项优化论证
- 可售比 = 计容面积 / 总建面

### 4.3 总图方案比选要求

- 完整新开地块或楼栋≥5栋的组团，须做方案比选
- 总图方案稳定后再推进后续深化
- 投标安排：2-3家设计单位，5-7天提交成果
- 提交内容：规划总图方案、户型方案、技术指标表、体块模型、示范区策划
- **总图需提供CAD文件和日照计算结果**
- **技术指标表需提供Excel表格，细化至楼栋面积**

### 4.4 户型面积表达要求

- 所有上报材料以**"综合实得面积"**为主表述
- 综合实得面积 = 报建面积 + 阳台/露台赠送 + 飘窗/设备平台赠送 + 私属电梯厅不计容
- 总图户配图需标注各户型赠送后综合实得面积及单价
- 户型平面需标注"综合实得面积、报建面积、赠送后得房率、赠送面积、赠送率"

### 4.5 成本适配"三个极限"

1. 营销判断客户能承受的售价极限
2. 反推项目投入的成本极限
3. 做到产品力的极限
4. 直投成本上限 = 货值 × (1 - 税前成本利润率) - 三费 - 地价
5. 四象限成本适配：示范区总成本、刚性成本、功能性成本、弹性成本

### 4.6 总图规划布置要点

1. 楼栋贴线布置（将间距用足在小区内部）
2. 总图资源配置（利好资源与不利因素量化分析）
3. 设备房、移交配套优先布局于首期建设范围
4. 非机动车位布置有专门原则

### 4.7 设计关注要点（产品线）

1. 核心筒设计
2. 墙垛预留
3. 外立面：冠顶设计、门窗分隔、标准层外墙涂料分缝、外轮廓
4. 室内样板房效果：竞品对标、成本拆解
5. 社区入口功能及流线
6. 示范区设计：展示策划、后勤办公、接待区
7. 地库专项：规模控制、单车指标控制、人防设计

## 九、总图→户型→立面的推进逻辑（从资料中观察到的）

### 9.1 实际推进顺序

3. **户型选型**（在总图方案确定后展示户型）→ PPT第8-12页
4. **指标核算**（贯穿始终，反复核对）→ Excel
5. **日照分析**（界外日照影响，导致方案调整）→ 微信沟通

- 从PPT和PDF中**未见立面内容**
