# ROM-AI 竞品研究计划：Airilab 及类似产品设计拆解

## 目标
对 https://global.airilab.com/stdio/workspace/173199 及类似竞品（建筑设计前期AI工作流/地产开发决策支持产品）进行专业拆解，输出面向ROM-AI研发的分析报告。

## 阶段划分

### Stage 1 — 并行信息搜集（Research）
加载技能：`deep-research-swarm`

并行部署多个研究代理：
- **研究员_Airilab**: 深度访问 global.airilab.com，抓取产品形态、功能模块、工作流、定价、目标用户等所有可见信息。
- **研究员_竞品生态**: 搜索并研究类似产品（Maket.ai, Testfit, Arcol, Hypar, Spacemaker, Finch 等），收集各自的核心定位、工作流、AI能力。
- **研究员_行业趋势**: 搜索"建筑设计前期AI工作流"、"地产开发决策支持"、"生成式设计平台"等行业趋势和市场份额信息。

### Stage 2 — 深度分析与写作（Analysis & Writing）
加载技能：`report-writing`

基于Stage 1搜集的原始材料，按以下结构逐一拆解每个目标产品：
1. 一句话定位
2. 核心价值链
3. 工作流拆解（5-8阶段）
4. 对ROM-AI的启发（映射到项目智能中心、数据基地、共创营地、会议纪要、汇报出口）
5. 产品机会（3短期+3中期+1长期）
6. ROM-AI研发建议（五类标注：已可实现/需要补数据/需要补UI/需要单独拍板/暂不做）

### Stage 3 — 整合与输出（Integration）
- 汇总所有分析，提炼对ROM-AI最有价值的5条启发
- 生成可进入Backlog的功能清单
- 明确不建议模仿的部分
- 一句话总结ROM-AI应该学什么
- 最终输出为结构化Markdown报告，并视情况转为.docx

## 关键约束
- 所有判断必须区分：官网明确写了什么 / 从官网推断了什么 / 对ROM-AI的建议是什么
- 研究必须覆盖Airilab及其提到的类似产品（至少3-5个）
- 报告需以中文撰写
