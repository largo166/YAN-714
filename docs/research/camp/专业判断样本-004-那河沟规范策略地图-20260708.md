# 专业判断样本-004 · 那河沟项目 · 模式路由判决（2026-07-08）

> 来源:C-P0 盲评后负责人对样本3 的批评原话,AI 照录进 14 字段格式。判决类型:**模式路由**(最关键样本——资料不足时,专业的输出既不是硬生成假概念,也不是"三个都不成立",而是切换到规范条件解读模式)。

| # | 字段 | 内容 |
|---|---|---|
| 1 | 项目背景 | 那河沟项目(襄阳);评审输入=多份规范文件拼合(《襄阳市城市规划管理技术规定》间距/退界/容积率计算规则/绿化篇/面宽退界调整通知),**无红线图、无指标、无业态、无现状、无周边关系、无办证阶段** |
| 2 | 原始概念 | 评审对象两版:①"垂直社区/界面缝合/层高弹性/景观渗透/时间分层"五方向(裸问版);②"候选均不成立"检验记录(链版全灭) |
| 3 | 方案亮点 | ①裸问版格式完整,给了可反应的选项集;②链版"敢下判断"被承认(锋利度勾给它) |
| 4 | 方案问题 | ①裸问五方向是**假概念**——从规范条文硬造设计概念,概念没有地块可长;②链版"三个都不成立"从诚实性上对,但**从专业服务上不够**——顾问不能只说"材料不足,概念不成立"就完了 |
| 5 | 总图问题 | 无红线无指标,总图判断无从谈起——这本身就是本样本的核心判断 |
| 6 | 产品问题 | 同上,业态未知,产品判断跳过 |
| 7 | 展示区问题 | 同上,跳过 |
| 8 | 造型问题 | 同上,跳过 |
| 9 | 报规/成本风险 | 规范文件本身可解读:间距表/退界新规/容积率计算规则(含通高条款,**但条款不完整,不得作为立论依据**——链版曾拿半截条款"不超过上…"造"套利模型",属违规立论) |
| 10 | 可保留内容 | 规范文件的条款整理工作;链版对"条款不完整不能下结论"的警觉 |
| 11 | 需要重写内容 | 全部概念产出作废——**该资料包不支持概念判断,只支持规范风险识别与设计自由度判断** |
| 12 | 推荐深化方向 | **切换到「规范策略地图」模式**,输出:①已知规范条款(完整引用) ②对总图的影响 ③对建筑面宽的影响 ④对退界的影响 ⑤对层高和计容的影响 ⑥对绿化率的影响 ⑦当前缺失资料 ⑧不应贸然提出的概念类型 ⑨下一步需甲方或设计团队确认的问题 |
| 13 | 可落图清单 | (本模式无图纸交付)替代交付物:规范策略地图一页 + **补资料清单**:红线/指标/业态/现状/周边关系/办证阶段/容积率完整条款 |
| 14 | 汇报话术 | "当前资料不足以生成设计概念,但可以先给规范策略地图和下一轮补资料清单——补齐红线与指标后,概念生成的地基才存在。" |

**判断结构标注(供 few-shot 提取):** 资料充分度判定先于概念生成;"拒绝服务"和"硬生成"都不专业,第三条路=切模式;半截条款不得立论(引用必须完整可查证);缺资料时的交付物=策略地图+清单,不是零。
