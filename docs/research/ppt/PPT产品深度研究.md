## 1. EasyMap Layout — 半自动图板排版器

### 1.1 一句话定位

**面向建筑/设计作品集的半自动 Portfolio Board Generator——从 OSM 分析图到排版出图链的最后一环，核心能力是"先排版骨架、后批量填图、再单点精调、最终矢量导出"。**【官网已证：easymap.uk/layout 页面标题与功能结构】

### 1.2 图片占位机制如何工作

EasyMap 的图片占位是其最核心的交互对象，机制如下：

| 维度 | 详情 | 证据来源 |
|---|---|---|
| **占位形态** | 黑色矩形区域，中心显示 "+ image" 文字，下方有描述标签（如 "Main render"、"Site plan 1:500"） | 截图直接观测 |
| **占位数量** | 随 starter 模板不同而变化，Concept 模板约 4-6 个图位 | 截图直接观测 |
| **批量填图** | 底部 "⇪ 批量填图 BATCH FILL" 按钮，点击后一键将多张图片按顺序填入所有占位区 | 截图直接观测 |
| **单点替换** | 点击任意图片占位区 → 弹出文件选择 → 替换单张图 | 截图 + 页面提示文字推断 |
| **图位类型标签** | 每个占位带语义标签（Main render / Site / Programme / Site plan 1:500 等），暗示批量填图时的映射规则可能按"标签语义→图片文件名/顺序"匹配 | 研究员推断 |
| **图片操作** | 无裁剪/滤镜/调整，纯替换；排版骨架决定图片展示框大小 | 研究员推断 |

> **关键推断**：BATCH FILL 的内部映射规则站点无文字说明。最可能的工作方式是：用户选择 N 张图片 → 按图片选择顺序或文件名顺序 → 依次填入编号图位。标签（如 "Main render"）仅用于人工识别，不参与自动匹配。【推断依据：页面上无 AI/智能匹配相关文字；先前研究已确认外部评测不存在】

### 1.3 页面模板体系

**Starter 起始版面（13 种）**：【截图直接观测】

| 模板名称 | 结构特征 |
|---|---|
| Concept | 大标题 + 主图 + 编号区块 + 概念描述 + 图标行 + 数据 |
| Analysis | 多图网格 + 分析文字 |
| Cover | 封面页 |
| 2×3 Grid | 六格图片矩阵 |
| Two-col | 双栏图文 |
| Hero+Text | 大图 + 文字叠层 |
| Infographic | 信息图 |
| Before/After | 前后对比 |
| Technical | 技术图纸风格 |
| 分析圆图 Site | 圆形分析图布局 |
| 主图+圆图 Hero | 主图 + 圆形图组合 |
| 杂志 Editorial | 杂志排版风格 |
| Strategy Board | 策略看板 |

**可加模块（11 种）**：Title 标题、Section 区块、Text 文字、Image 图片、Circle 圆图、Caption 图注、Icons 图标行、Legend 图例、Stat 数据、Process 流程、Divider 分隔

**纸张与方向**：A3 / A2 / A1；横 Land / 竖 Port

**主题（5 种）**：冷白黑红 Red、纯黑白 Mono、莫兰迪灰 Morandi、深色 Dark、撞色 Clash

**字体（6 种）**：Archivo 粗黑、Oswald 窄高、Playfair 衬线、Fraunces 优雅、Manrope 细体、Franklin 经典

> 模板选择方式：左侧缩略图网格，一键点击即铺完整版面。页面提示文字："点 starter 一键铺好整张板，再换图换字。点任意模块编辑；悬停模块右上角 × 删除。"

### 1.4 用户工作流

```
选择纸张(A3/A2/A1) + 方向(横/竖)
    ↓
选择主题(配色) + 字体
    ↓
选择 Starter 模板（一键铺满版面，生成黑色占位区）
    ↓
【可选】点击 ADD BLOCK 添加额外模块
    ↓
批量填图（BATCH FILL：选择多张图片一键填入所有占位）
    ↓
单点精调（点击任意占位替换单张图 / 点击文字编辑内容）
    ↓
【可选】撤销 UNDO / 清空 Clear
    ↓
导出（PDF / PNG / SVG(AI)）
```

### 1.5 协作功能

**无协作功能。** 纯单机浏览器工具，无账户体系、无分享链接、无多人编辑。【官网已证：页面无登录/分享/协作入口】

### 1.6 是否有 AI 生成内容

**无。** 纯模板驱动 + 人工填图。无 AI 生成文字、无 AI 配图、无智能推荐。【官网已证：页面无任何 AI 相关标识或功能】

### 1.7 对 ROM-AI 的启发

| ROM-AI 模块 | 可借鉴点 | 边界/注意 |
|---|---|---|
| 图片槽位体系 | EasyMap 的 "+ image" 占位 + 语义标签（Main render / Site plan）是图片作为一等对象的正确形态 | ROM-AI 应增加 `asset_type` 字段到槽位，让"批量填图"有映射依据 |
| 批量填图工作流 | "预填占位→一键确认→单点精调"的三段式值得借鉴 | **必须加确认步骤**，禁止静默铺满（撞红线） |
| Starter 模板 | 13 种模板的分类逻辑（Concept/Analysis/Cover/Grid/Editorial）可迁移为建筑汇报专用 starter | 需改为中文建筑语境（如"前期研判"/"案例对标"/"概念生成"） |
| 导出格式 | PDF + PNG + SVG(AI) 三格式覆盖 | PPTX 优先，SVG 中期，PNG 次之 |
| 纸张尺寸 | A3/A2/A1 + 横竖 | 增加 16:9 幻灯片尺寸 |
|  Undo/Clear | 撤销栈和清空是基本交互保障 | 前端状态管理需预留 |

## 2. Gamma — AI 原生内容生成器

### 2.1 一句话定位

**AI 驱动的演示文稿/文档/网页三合一生成器，以"提示词→AI 大纲→主题→完整 Deck"为核心工作流，网页原生 Card 系统让内容像流体文档一样可滚动、可嵌入、可交互。**【官网已证：gamma.app 首页文案 + 搜索辅证】

### 2.2 图片占位机制如何工作

| 维度 | 详情 | 证据来源 |
|---|---|---|
| **AI 自动配图** | 生成 Deck 时自动插入 AI 生成图或网络搜索图；用户可选择 "Web search / Stock photos" 避免 AI 幻觉 | 搜索辅证 |
| **Suggest images** | 编辑时右侧出现 "Suggest images" 按钮，AI 根据上下文推荐图片 | 截图直接观测 |
| **单点替换** | 点击任意图片 → 上传/搜索/AI 生成替换 | 搜索辅证 |
| **AI 图片生成** | 支持多模型：Flux Fast、Ideogram 3.0 Flash（免费）；高级模型付费 | 搜索辅证 |
| **图片成本** | 基础模型 2 credits/张，高级模型最高 50 credits/张；免费账户共 400 credits | 搜索辅证 |

Gamma 的图片处理是**生成时自动填充**，而非先占位后填图。这是与 EasyMap 根本不同的范式。

### 2.3 页面模板体系

**主题系统**：一键切换整个 Deck 的视觉风格（配色、字体）。【搜索辅证】

**导入品牌**：可上传品牌 PPT，Gamma 自动提取配色和字体方案。【搜索辅证】

**Smart Layouts**：多栏网格、时间线、对比框等自动排版。【搜索辅证】

**格式选择**：Default（流体网页）/ Traditional 16:9（适合导出 PPT）/ Mobile / Square。【搜索辅证】

模板选择方式：AI 生成后统一应用主题，非先选模板再填内容。

### 2.4 用户工作流

```
输入阶段（四选一）：
  ├─ Generate：一行提示词生成完整 Deck
  ├─ Paste in text：粘贴大纲/笔记
  ├─ Import file/URL：导入现有文档或网页
  └─ Generate from template：结构化模板填空
    ↓
AI 生成大纲（可编辑：调整结构、受众、语气、语言）
    ↓
选择主题 / 导入品牌配色
    ↓
AI 生成完整 Deck（30-60 秒）
    ↓
编辑精调：
  ├─ 文本直接编辑
  ├─ Sparkle AI Agent：自然语言指令修改（"make this more professional"）
  ├─ 换图 / 调布局
  └─ 添加多媒体嵌入（YouTube / Miro / Airtable / Spotify 等）
    ↓
导出 / 分享：PDF / PPTX / Google Slides / PNG / 公开链接 / 转为网页
```

### 2.5 协作功能

| 功能 | 详情 | 限制 |
|---|---|---|
| 实时协作 | 多用户同时编辑 | 需 Pro 付费计划 |
| 分享链接 | 生成公开/私密链接 | 免费版可用 |
| 数据分析 | 追踪链接查看次数、每张卡片的停留时间 | 免费版基础分析 |
| 评论 | 卡片级评论 | 搜索辅证 |

### 2.6 对 ROM-AI 的启发

| ROM-AI 模块 | 可借鉴点 | 边界/注意 |
|---|---|---|
| DeckPlan 编排 | Gamma 的"大纲→主题→生成"流程与 ROM-AI 的 DeckPlan 理念一致，但 Gamma 是全自动，ROM-AI 应保留人工审查大纲环节 | 已批决议：上游结构化→PPT，不是提示词→PPT |
| AI Agent 编辑 | Sparkle Agent 自然语言改稿（"make this more professional"）→ 预览 → 接受/撤销 | 可借鉴但排中期，先跑通基础渲染 |
| 主题一键切换 | 整个 Deck 配色字体一键变换 | 需先定义 ROM-AI 品牌模板系统 |
| 多媒体嵌入 | 嵌入 Miro/Airtable/YouTube 到卡片 | 建筑汇报场景需求低，暂不做 |
| 网页原生呈现 | 流体 Card 系统可滚动浏览 | ROM-AI 以 PPTX 导出为最终目标，网页预览可做辅助 |
| **不可学** | 全自动生成不审即出、AI 图片幻觉、fluid web→PPT 导出格式崩坏 | 搜索辅证：Gamma 导出 PPT "频繁破坏格式"是最大投诉 |

## 3. Beautiful.ai — Smart Slides 自动排版

### 3.1 一句话定位

**介于传统幻灯片编辑器和完全 AI 生成器之间的自动排版工具——你专注于内容输入，Smart Slides 实时处理间距、对齐和视觉平衡，让非设计师也能输出零失误的专业版面。**【官网已证：beautiful.ai 首页 + 搜索辅证】

### 3.2 图片占位机制如何工作

| 维度 | 详情 | 证据来源 |
|---|---|---|
| **自动重排** | 添加图片后，Smart Slide 自动调整文本环绕、间距重分配；删除图片后剩余元素自动重分布 | 搜索辅证 |
| **内置素材库** | 集成 stock 图库和 icon 集 | 搜索辅证 |
| **图片限制** | 无法自由拖拽图片到任意位置；Smart Slide 系统决定图片位置和大小 | 搜索辅证 |

Beautiful.ai 的图片处理是**内容驱动排版**——图片作为内容元素之一，触发整体布局重算。没有显式的"占位区"概念，但模板中有预设的图片插槽。

### 3.3 页面模板体系

**Smart Slide 布局（300+ 种）**：【搜索辅证】

- 按用途组织：pitch decks、project updates、training materials、marketing plans 等
- 预置类型：timelines、comparison grids、data charts、team bios、quotes、agendas、pricing 等
- 每种布局内置设计智能，自动对齐

**三种创建方式**：【官网已证】

1. **Create with AI**：先生成大纲，再生成 Deck
2. **Slide by slide**：从 300+ Smart Slide 布局中逐页选择
3. **Designer templates**：完整多页叙事模板

**品牌标准化**：Define brand colors, fonts, logos once → slides adapt automatically；Shared themes 保持团队一致。【官网已证】

### 3.4 用户工作流

```
创建方式三选一：
  ├─ AI 生成：输入主题 → AI 出大纲 → 确认后生成
  ├─ 逐页构建：选择 Smart Slide 类型 → 输入内容 → 自动排版
  └─ 设计师模板：选择完整模板 → 替换内容
    ↓
内容编辑（文本/图片/图表/图标）
    ↓
Smart Slides 自动调整布局
    ↓
协作审阅（评论、实时编辑）
    ↓
导出（PPTX / PDF）或分享链接
```

### 3.5 协作功能

| 功能 | 详情 | 限制 |
|---|---|---|
| 实时协作 | 多用户同时编辑 | Team/Enterprise 计划 |
| 评论 | 单页评论 | Team/Enterprise 计划 |
| 版本历史 | 自动保存历史版本 | Team/Enterprise 计划 |
| 权限控制 | 编辑/查看角色分离 | Team/Enterprise 计划 |
| 分析 | Viewer analytics（查看次数、互动数据）| 搜索辅证 |

> **定价跳跃**：Pro $12/月（单人）→ Team $40/人/月。小团队 5 人即 $2400/年。【搜索辅证】

### 3.6 对 ROM-AI 的启发

| ROM-AI 模块 | 可借鉴点 | 边界/注意 |
|---|---|---|
| 自动排版规则 | "输入内容→自动对齐"的 Smart Slide 机制可大幅降低前端排版成本 | 建筑汇报的版式更复杂（大图+小字+多图网格），规则需自定义 |

## 4. Canva Magic Design — 生态型 AI 演示扩展

### 4.1 一句话定位

**全球最大设计平台（1.5 亿用户）内的 AI 演示生成功能——Magic Design 将文本提示转为结构化幻灯片，核心优势不是 AI 本身，而是 100M+ 素材库、Brand Kit 生态、以及一键转社媒/视频/印刷的多格式复用能力。**【搜索辅证 + 官网截图】

### 4.2 图片占位机制如何工作

| 维度 | 详情 | 证据来源 |
|---|---|---|
| **Magic Design 自动配图** | AI 从 Canva 素材库自动选择匹配图片；生成 3-8 个版本供选 | 搜索辅证 |
| **100M+ 素材库** | 照片、插画、图标、视频、音频直接在编辑器内搜索拖拽 | 搜索辅证 |
| **AI 图片生成** | Magic Media（文本生图）；Dream Lab Pro 月限 500 张 | 搜索辅证 |
| **AI 图片编辑** | Background Remover（去背）、Magic Expand（扩图）、Magic Erase（消除）、Magic Grab（主体分离）、Magic Edit（自然语言改图） | 搜索辅证 |
| **图片替换** | 拖拽替换，Elements 面板直接搜索 | 搜索辅证 |

Canva 的图片处理是最全面的——既有 AI 自动配图，也有手动从海量素材库选择，还有 AI 编辑工具链。

### 4.3 页面模板体系

**Magic Design 生成**：输入提示 → 生成 3-8 个模板变体 → 选择进入编辑器。【搜索辅证】

**传统模板库**：数千免费/付费演示模板。【搜索辅证】

**Brand Kit（Pro）**：存储 Logo、品牌色、字体 → 一键应用到 AI 生成 Deck。【搜索辅证】

**Brand Hub（Teams）**：共享资产、审批工作流、高级分析。【搜索辅证】

AI 生成 3-8 个版本
    ↓
选择最接近的版本
    ↓
编辑内容：
  ├─ 文本：直接编辑 或 Magic Write AI 重写
  ├─ 图片：搜索素材库 / AI 生成 / 上传替换
  ├─ 数据：粘贴数据自动生成图表
  └─ 品牌：应用 Brand Kit（Pro）
    ↓
协作审阅（实时协作、评论）
    ↓
导出 / 复用：
  ├─ PPTX / PDF / MP4
  ├─ 一键 resize 为 Instagram / LinkedIn / YouTube 等

| 素材库生态 | Canva 的 100M+ 素材库是其护城河；ROM-AI 的护城河应是**本地项目资产池 + 类型标签** | 已有 image_assets 基础，需做前端选图网格 |
| Brand Kit | 事务所品牌色/字体/Logo 一次定义，全局应用 | 需单独拍板品牌模板系统 |
| 多格式复用 | 一键 resize 到社媒/视频/印刷 | 建筑场景需求低，但"汇报底稿→不同甲方口径"是类似需求 |
| AI 图片编辑 | Magic Expand/Erase/Edit 等工具链 | 非核心需求，暂不做 |
| **不可学** | 通用设计平台而非建筑专用；AI 生成内容泛化严重；PowerPoint 导出常丢失格式 | 搜索辅证："Exporting to PowerPoint sometimes loses Canva-specific design elements" |

## 6. 跨站综合：对 ROM-AI PPT 线的系统启发

### 6.1 图片槽位与批量填图（EasyMap × ROM-AI 资产池）

五款产品对图片的处理分两种范式：

| 范式 | 代表 | 特征 | ROM-AI 适用性 |
|---|---|---|---|
| **先占位后填图** | EasyMap | 黑色占位区 → 人工/批量替换 | ✅ **最匹配建筑工作流**——设计师需要控制每张图的精确位置 |
| **生成时自动配图** | Gamma/Canva/Pitch | AI 自动选图或素材库匹配 | ⚠️ 辅助可用，但不可作为主力——建筑图不能 AI 幻觉 |
| **内容驱动排版** | Beautiful.ai | 添加图片触发整体重排 | ⚠️ 限制太多，建筑师需要精确控制 |

**ROM-AI 应采用"EasyMap 占位骨架 + 本地资产池"模式：**

```
DeckPlan JSON（含 visual_slots）
    ↓
渲染为占位骨架（黑色/灰色占位区 + asset_type 标签）
    ↓
批量填图：按 asset_type 匹配本地资产池候选图 → 预填预览 → 人工确认
    ↓
单点精调：点击槽位 → 资产网格（按项目/类型筛选）→ 替换
    ↓
再渲染为 PPTX
```

### 6.2 模板体系设计建议

综合五家经验，ROM-AI 模板体系应：

| 层级 | 内容 | 参考来源 |
|---|---|---|
| **纸张/尺寸** | A3/A2/A1 + 16:9 幻灯片 + 竖版 | EasyMap |
| **品牌主题** | 事务所品牌 Kit（色/字体/Logo）| Canva Brand Kit + Beautiful.ai Shared Themes |
| **Starter 类型** | 前期研判 / 案例对标 / 概念生成 / 方案比选 / 技术图纸 / 总平面 / 效果展示 | EasyMap 分类逻辑 + 建筑场景定制 |
| **模块组件** | 标题区 / 大图位 / 多图网格 / 数据指标 / 图标行 / 图注 / 分隔线 | EasyMap ADD BLOCK |
| **布局规则** | 自动对齐但不强制——建筑师需要 Override 能力 | Beautiful.ai Smart Slides 的反面教训 |

### 6.3 协作编辑优先级

按 Pitch 的协作深度，ROM-AI 短期可借鉴的协作功能：

1. **评论**（页面级）— 建筑师审阅汇报底稿时必需
2. **版本历史** — 每次 AI 生成/人工替图后自动快照
3. **Slide 状态** — 哪页已确认、哪页缺图、谁负责
4. **实时协作** — 排中期，非 MVP

### 6.4 导出策略

| 格式 | 优先级 | 参考 |
|---|---|---|
| PPTX | P0（已有后端能力，前端接按钮即可）| 全部竞品支持 |
| PDF | P1 | EasyMap + 全部竞品 |
| PNG | P2 | EasyMap 支持 |
| SVG | P3 | EasyMap 支持，中期 |
| 网页预览 | P2（Gamma 网页原生体验好）| Gamma |

### 6.5 最重要的边界判断

| 能力 | 该做 / 不该做 | 理由 |
|---|---|---|
| AI 自动配图 | ❌ **不该做** | 建筑图不能 AI 幻觉；无合适图就黑占位/标缺图（已批决议） |
| 批量填图预填+确认 | ✅ **必须做** | 借鉴 EasyMap 意图，但必须加确认闸（红线） |
| 网页原生 Deck | ⚠️ 可做预览，不做主形态 | ROM-AI 以 PPTX 为最终交付物 |
| 素材库外拉 | ❌ **不做** | 撞 local-first 红线；用本地项目资产池 |
| 协作评论 | ✅ **中期做** | Pitch 证明这是团队场景刚需 |
| 品牌 Kit | ✅ **需拍板** | Canva/Beautiful.ai 都验证其价值 |

## 8. 一句话总结（每产品）

- **EasyMap**：学"占位骨架 + 批量填 + 单点换 + 矢量导出"的半自动排版闭环；素材源换成本地资产池 + 类型标签。
- **Gamma**：学"AI 大纲编排 + 主题一键切换 + Agent 改稿"；不学 fluid web 做主形态、不学自动配图。
- **Beautiful.ai**：学"自动排版规则 + 品牌主题一致性"；不学无免费版、不学强制布局限制、不学慢更新模板库。
- **Canva**：学"素材库生态 + Brand Kit + 多格式复用"；不学通用设计平台形态、不学 AI 泛化配图。
- **Pitch**：学"Slide 状态 + 版本历史 + 演示分析"的协作深度；不学固定 11 页输出、不学英文-only。

> **贯穿五站的核心判断**：ROM-AI 的 PPT 线不应追求"更强 AI"或"更多模板"，而应锚定"**本地项目资产 + 结构化判断 + 建筑师主导替图**"的差异化——这正是五家竞品要么没有（本地资产）、要么做得过度（AI 自动配图）的领域。
