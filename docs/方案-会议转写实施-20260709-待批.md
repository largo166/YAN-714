## 一、链路(只加最左一环,右侧全复用)

```
录音文件(mp3/wav/m4a)
  │  POST /{pid}/meetings/from-audio(新,异步job)
  ▼
faster-whisper large-v3 本地转写(首启下载模型,不进exe)
  + pyannote 说话人分离 → 按时间重叠对齐
  ▼
Meeting(transcript_source="asr", segments_json=[{text,speaker_key,start_ms,end_ms}])
  │  ← 模型/缝早已预留:models.py:353-355,从未通电
  ▼
既有 generate_minute → build_prompt 已按段吃 speaker_key(meeting.py:44)
  → 五段式 + 黑话转译 + 对内/外版(零改动)
```
