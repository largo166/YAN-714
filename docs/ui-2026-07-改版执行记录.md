## 9. 前端工程化约束:React + Vite + Tailwind + TypeScript(2026-07-05 拍板)

## 环境债(2026-07-06 端口误杀事故落档)

**进程拓扑图见 [docs/进程拓扑.md](进程拓扑.md)**(五要素:进程清单/父子关系/端口契约/启停顺序/变更即更新)。三条硬约束:
