# 五板块粒子背景 · 已批裁决(2026-07-09 夜)

## 已批决议(方向 OK,三条硬要求)
1. **极慢极淡**:比小样再收敛一档——负责人天天盯着干活的界面,背景不抢注意力、不久看疲劳。
2. **可关闭**:设置页给开关(静态背景 / 粒子背景),落地晕动症红线。默认可先静态或极淡,由负责人定档。
3. **不拖性能**:切板块/滚动不掉帧,dist 实测确认。
4. 接线 ParticleField 替换/叠加 SeaCanvas;过对抗审查(卸载/性能/遮挡)+ dist 实测。
5. 锁版视觉面绑定:五板背景改动与晕动症红线一起,本决议即拍板依据。

## 边界
canvas 2D 轻量(非 three.js);prefers-reduced-motion 直接静态;开关状态存 LS。
