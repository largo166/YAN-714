# 五板块粒子背景 · 已批裁决(2026-07-09 夜)

## 已批决议(方向 OK,三条硬要求)
1. **极慢极淡**:比小样再收敛一档——负责人天天盯着干活的界面,背景不抢注意力、不久看疲劳。
2. **可关闭**:设置页给开关(静态背景 / 粒子背景),落地晕动症红线。默认可先静态或极淡,由负责人定档。
3. **不拖性能**:切板块/滚动不掉帧,dist 实测确认。
4. 接线 ParticleField 替换/叠加 SeaCanvas;过对抗审查(卸载/性能/遮挡)+ dist 实测。
5. 锁版视觉面绑定:五板背景改动与晕动症红线一起,本决议即拍板依据。

## 边界
canvas 2D 轻量(非 three.js);prefers-reduced-motion 直接静态;开关状态存 LS。

## 修正:全线统一粒子海(2026-07-09,负责人骂醒——口令闸背景漏改)
**问题**:口令闸(GateScene)背景一直是旧 SeaCanvas 网点 dither,开机影片(FilmSea 粒子海)→口令闸时背景"啪"掉回粗网点,突兀。上一轮我只把 ParticleField 接进五板块,漏了口令闸,还错报"正常态"。
**裁决(负责人:全线统一粒子海)**:开机影片/口令闸/五板块三处背景**全用同一套 FilmSea 粒子海**,彻底消除断层。
**实现**:
- FilmSea 加 `animated` prop(静态档/减动效→锁一帧不跑 rAF);退化视口防呆(clientW/H 夹 [1,4096],防 headless 1px 算出天文尺寸爆 GPU)。
- AppShell:phase!=='film' 时 `bg==='sea'?SeaCanvas:FilmSea(animated=bg!=='static')`;**默认档从 sea 改 particle**(全线统一=默认即影片同款海)。
- 设置「板块背景」三档:粒子海(默认)/静止/网点(旧 fbm 保留可选)。
- 弃用 ParticleField.tsx(删),背景统一走 FilmSea。SeaCanvas 保留为「网点」档,不删。
**验证**:tsc -b/build/vitest 全绿;preview_eval 确认 gate 相 backdrop canvas = FilmSea(webgl,z-0 opacity-90);
**诚实缺口**:dist 像素视觉本环境仍无法验(preview 视口 1px、CDP 反复掉)——机制已确认,观感待负责人下次启动眼验(验收标准见 本轮封板-20260709.md 裁决一,三条同款)。
