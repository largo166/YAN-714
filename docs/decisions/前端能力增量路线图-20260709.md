## 五项前端增量(负责人原文口径)

### ① P1-1 资料类型细分(已有 design_doc_type)
前端加:检索/文件列表里**类型筛选下拉**(效果图/图纸/演示/表格…)+ 每个文件卡**类型标签** + 分错了能**手动改类型**的小菜单。
> 最简单——P0+ 检索浮层已有分组,把类型从七类换细分类 + 加手动改。
> 状态:分组已切 16 类(e7ad789);筛选 UI 小样已排(2026-07-09 批"要,先小样");手动改类型待小样一并考虑。

### ② OCR
前端加:几乎不用新 UI。只需文件卡上**"含 OCR 文字"小标记**,让用户知道这张图能搜。OCR 是后台能力,不是前端功能。

### ③ 图片资产抽取(已有 image_assets/缩略图)
前端加:**图片资产池**——项目里所有图的缩略图网格、按类型筛(效果图/总图/剖面)、点开看大图。是后面"报告自动配图"的前置界面,先把"能看图、能筛图"做出来。
负责人结构定稿(参考已确认小样风格):
- 数据源:读现有 image_assets(缩略图/来源文件/页码/caption)+ design_doc_type,**不新建抽图逻辑**;
- 布局:顶部项目范围+类型筛选条(数字=真实计数)→ 缩略图网格(缩略图+文件名+类型标签+页码角标,OCR 过的加 OCR 标)→ 右侧详情面板(大图+类型可改+来源+尺寸+"用于报告"占位按钮);
- 交互:点图选中→右侧详情;"改类型"下拉写回 design_doc_type;"打开原文件"走 reveal;"用于报告"**占位**(本轮不实现报告);
- 审美:海天设计令牌,不用 shadcn 默认样式,不做商业模板感;
- 边界:纯前端接线+读现有接口,不动 image_assets/分类后端逻辑,前端 build 过,不接外部 UI skill。

### ④ 六个核心 skill(已打包 release-internal)
前端加:斜杠命令(/ppt /img)+ 技能卡入口,结果卡进对话流(方向此前已定)。

### ⑤ exporters(PPTX 导出)
前端加:成果卡上一个**"导出 PPTX/打印"按钮**——后端能力已在,前端就一个按钮。
