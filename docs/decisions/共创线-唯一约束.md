# 共创线 · 唯一约束(2026-07-09 定,取代此前全部共创裁决文档)

## 一条硬约束(碰了必须停下问负责人)
**「AI 自动建筑判断」不合入 ROM-AI 产品线** —— 即:自动识别关键分叉 / 自动案例类比 / AI 主动押注推荐,三者任一进产品线都要先批。
判断标准就一句:**碰没碰"AI 替人做建筑判断且进产品线"。没碰,直接做;碰了,停下来问。**

## 解封条件(达到即自动提请,不到不议)
人填共创卡 **≥ N 份 + 盲评通过**,双门齐过 → 上述"AI 自动建筑判断"逐项解封。N 待负责人定(AI 提议 15,现有专业判断样本 4 份)。

## 三条自查红线(开发时自查,不再走审批)
1. 第一步永远"AI 摊草稿、人圈选定稿"——不做全自动识别分叉。
2. 写回认知脊椎必须"用户改写后确认"——不改文本不写 `status=confirmed`。
3. 案例启发只用抽象设计模式;具体项目类比一律标"待人工核实"。

## 已解除管制(直接做,不报批)
Codex skill / 方法论文档 / 共创卡容器·UI·认知写回通路 / 判断→PPT 骨架链路。
