## 工程现实与开工前核实清单(AI 提请,未裁决部分)

1. **pyannote 依赖 torch**(体积大),不可随 exe → 分离栈走"首次启用时安装"或评估 sherpa-onnx 跑 pyannote 分割模型的 ONNX 版(复用已随包 onnxruntime,免 torch)——**开工首日实测二选一,不改变"v1 带分离"的裁决**。
2. pyannote 官方模型是 HF gated(需账号+token),国内网络有摩擦 → 镜像/离线分发方案要落。
3. **分离≠身份**:pyannote 输出 speaker-1/2 聚类,不直接给"甲方/我方"→ v1 落"分离+UI 可改名",不承诺自动认甲方。
4. large-v3 下载体积(约 1.5–3GB 视量化档,待核实)+ CPU 转写速度实测(1 小时录音耗时)→ 下载进度 UI + HF_ENDPOINT 镜像配置必须有。
5. faster-whisper 依赖 PyAV 解码 mp3/m4a(自带 ffmpeg 库,免系统 ffmpeg,打包收集待核实——同 onnxruntime 收集一族的坑)。
6. 许可证:faster-whisper/CTranslate2 MIT;whisper large-v3 权重 Apache-2.0;pyannote 代码 MIT、模型许可**单独确认**(笔记§五-2 纪律)。
7. **建筑术语加分项(AI 建议,待批)**:faster-whisper 的 initial_prompt 热词——把认知脊椎项目词典(项目名/甲方名/地名/常用术语)喂进转写,提专业词准度。认知脊椎直接变现,垂类护城河。
