# ROM-AI 公网部署与访问闸

## 已批决议（2026-07-11）

- 用户明确要求：读取 ROM-AI 当前开发完成内容，将后端一并部署到公网；前端改用公网 API；增加登录或访问密码，避免内部资料泄露。
- 公网形态采用 FastAPI 同源托管前端 `dist`，浏览器以当前公网 Origin 作为 API 基址。前端与 API 不拆域，避免 Cookie/CORS 漂移。
- 访问控制必须在服务端生效：未认证请求不能直接调用项目、文件、知识库等 API。原“管理驾驶舱口令”只用于本机板块解锁，不等同于公网鉴权。
- 本地桌面形态默认不启用公网访问闸；公网进程通过 `deploy/public.env` 显式开启，密钥不进 git。
- 当前无 Cloudflare 账号、域名或 named tunnel token 时，只能用 Quick Tunnel 做真实公网验收；固定域名与开机自启属于下一步部署凭据接入，不得把临时 URL 冒充生产 SLA。
- 公网后端 origin 只监听 `127.0.0.1:8010`，与当前被既有 Python 进程占用的本地 8000 隔离；公网只能经 HTTPS 隧道到达。

## 安全契约

- `/health` 与 `/api/access/status|login|logout` 可匿名访问。
- 其余 `/api/*`、`/docs`、`/redoc`、`/openapi.json` 未登录返回 `401`。
- 登录成功只签发 `HttpOnly + SameSite=Strict` Cookie；公网形态启用 `Secure`，默认 12 小时失效。
- 前端只有访问状态确认成功后才挂载内部五板应用；失败、未配置、口令错误均显示诚实状态。

## 运行入口

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-public.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-public-backend.ps1
powershell -ExecutionPolicy Bypass -File scripts\start-public-tunnel.ps1
```
