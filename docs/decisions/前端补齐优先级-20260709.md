### 追加裁决（2026-07-09 晚 · 手写 HTML 小样被否）
- **背景**：Step 4 主控手写了 5 个静态 HTML 小样（`docs/prototypes/01~05`）。用户看后判定"太丑、ChatGPT 味、不配锁版海天视觉——这么改还不如回到之前"。
- **裁决**：
  1. **5 个 HTML 小样全部删除**（已执行；`docs/prototypes/` 空目录一并移除）。它们只是草稿、从未进代码、不影响任何现役页面。
  2. **以后不再手写丑 HTML 小样。** 要推进新功能时，**直接用现有 seasky 组件（`GlassCard`/`PillButton`/`StatBlock`/海天 token）在真 React 代码里做**，贴锁版视觉，`npm run build` 出 dist 给用户看真效果。
  3. 若确需静态草稿预览，**只能复用已获用户认可的那套海天 CSS**（`prototypes/database-asset-pool-drawer-state-20260709.html` 的风格），**严禁自创新样式/新配色/emoji 图标/居中暗色弹窗那套通用审美**。
- **教训**：锁版视觉面是冻结铁律区，任何视觉产出必须贴现有组件与 token，不能另起炉灶——另起炉灶=必丑=白做。

### 验收地址铁律（2026-07-09 晚 · 踩坑落档）
- **看 dist 真效果，一律访问 `http://127.0.0.1:8000/seasky.html`**（后端同源托管 dist，最贴近 exe/pywebview 打包形态；`/api` 同源打真后端）。
