# 会议转写 · 模型放置说明(离线兜底 + 下载源)

> 录音不出本机;模型不进 exe(1.6GB),首次使用时下载。三种拿到模型的方式,任选:

## 方式一:自动下载(默认,ModelScope 国内源)
首次点"上传录音"时自动拉。`.env` 里 `model_source=modelscope`(默认)。
- 转写模型:ModelScope `pengzhendong/faster-whisper-large-v3-turbo`(CT2 格式,约 1.6GB)
- 分离模型:随包或从 GitHub k2-fsa release(见方式三)

## 方式二:切 HuggingFace 源(可直连 HF 的机器)
`.env` 里改 `model_source=hf`(可选再配 `hf_endpoint`)。
- HF repo:`deepdml/faster-whisper-large-v3-turbo-ct2`

## 方式三:离线手动放置(彻底不依赖在线下载)
把模型文件放进数据目录的 models 子目录,程序检测到即用,永久生效。

**放置目录**(冻结态 exe):`%LOCALAPPDATA%\ROM-AI\models\`
**放置目录**(开发态):`backend/data/models/`(或 `ROMAI_DATA_DIR/models/`)

**目录结构**:
```
models/
  whisper-large-v3-turbo/       ← 转写模型(必须含 model.bin ~1.6GB + config.json + tokenizer.json + vocabulary.json + preprocessor_config.json)
  sherpa-onnx-pyannote-segmentation-3-0/model.onnx   ← 说话人分离·分段模型
  spk_embed_zh.onnx             ← 说话人分离·中文声纹 embedding
```

**转写模型下载地址**(任选):
- ModelScope:https://modelscope.cn/models/pengzhendong/faster-whisper-large-v3-turbo/files
- HuggingFace:https://huggingface.co/deepdml/faster-whisper-large-v3-turbo-ct2/tree/main

**分离模型下载地址**(GitHub k2-fsa release,国内可达):
- 分段:https://github.com/k2-fsa/sherpa-onnx/releases/download/speaker-segmentation-models/sherpa-onnx-pyannote-segmentation-3-0.tar.bz2(解压取 model.onnx)
- 中文 embedding:https://github.com/k2-fsa/sherpa-onnx/releases/download/speaker-recongition-models/3dspeaker_speech_eres2net_base_sv_zh-cn_3dspeaker_16k.onnx(重命名为 spk_embed_zh.onnx)

## 三态诚实
模型没放/没下 → 设置页显"转写模型未下载,首次使用时下载";下载失败 → 如实报错,不假装就绪。分离模型缺 → 转写照常,降级单说话人(如实标注)。
