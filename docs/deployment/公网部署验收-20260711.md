## 尚未成为长期生产部署的原因

Cloudflare 官方将 Quick Tunnel 定义为开发/测试用途：URL 不固定、无 SLA，且不支持 SSE。ROM-AI 的入库进度使用 SSE，所以当前临时地址可做登录/API/常规页面验收，但不能作为完整长期生产入口。

长期闭环需要以下任一项外部凭据：

1. Cloudflare 账号下的 named tunnel token + 已接入 Cloudflare 的域名；或
2. 另一家支持固定 HTTPS 域名与 SSE 的云平台账号/部署凭据。

拿到 named tunnel token 后，将隧道注册为 Windows 服务并绑定固定域名；后端仍保持只监听 `127.0.0.1:8010`。
